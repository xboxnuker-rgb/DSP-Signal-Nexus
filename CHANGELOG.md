# Changelog

All notable changes to Signal Nexus are documented here.

## 0.2.13 - 2026-10-02

- Added the production-ready combined Signal Nexus building.
- Integrated Traffic Monitor scanning, alarms, speaker controls, item filtering, and IP settings.
- Added Holo Beacon colour, visibility, display mode, Dark Fog beaconing, height, radius, memo, and tag controls to the monitor window.
- Added Tesla Tower power-grid connection and coverage.
- Added full building copy/paste and Shift-click duplication support for combined settings.
- Added blueprint and save/reload persistence.
- Restored vanilla Traffic Monitor and Proliferator recipe positions when other content mods modify build menus.
- Fixed the orphaned Holo Beacon popup and settings panel layout when speaker controls expand.
- Fixed duplicate-placement preview errors in BuildToolOpt/DeliverySlotsTweaks mod stacks.

## 0.1.0 - 2026-10-01

- Initial combined-building prototype.
